# Raj Porwal — Portfolio

Personal portfolio site. Static single-page site (`index.html`), deployed on Vercel.

## Local preview

Open `index.html` in a browser, or run a static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Deploy

Hosted on Vercel. Every push to `main` triggers an automatic deployment.
